# Scope

## In Scope

- Raw work-experience input
- Resume bullet generation
- Prompt V1, V2, and V3
- Factual preservation
- Hallucination testing
- Clarity and conciseness
- Instruction following
- Professional quality
- Ambiguity handling
- Before/after prompt comparison
- Defect logging
- Root-cause analysis
- Evidence capture

## Out of Scope

- Real ATS integration
- Automatic job applications
- Guaranteed ATS scoring
- Production deployment
- Real candidate ranking

## Data Scope

Only synthetic sample inputs are used. No confidential employer, client, customer, production, or personally identifiable data should be added to the repository.

## Evaluation Scope

Evaluation applies only to the tested prompts, test inputs, selected model/settings, controlled conversation conditions, and testing period.
